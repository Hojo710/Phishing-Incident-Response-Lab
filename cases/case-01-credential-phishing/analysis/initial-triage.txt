CASE 01 - CREDENTIAL PHISHING
INITIAL TRIAGE

User Report:
User reported an unexpected email claiming that their Microsoft 365 password would expire today. The user reported that they did not click the link.

Initial Observations:

1. Sender Identity
The message claims to originate from "Microsoft 365 Security," but the sender uses the domain microsoft-account-alert.example rather than an official Microsoft domain.

2. Reply-To Mismatch
The Reply-To address uses secure-login.example, which differs from the sender domain. This mismatch increases suspicion and requires further investigation.

3. Email Authentication
The message authentication results show:
- SPF: FAIL
- DKIM: NONE
- DMARC: FAIL

These results increase suspicion because the message claims to represent Microsoft but does not successfully authenticate.

4. Suspicious Link
The message directs the recipient to:
https://login-microsoft365.example/verify

The destination domain differs from both the claimed Microsoft identity and the sender domain.

5. Social Engineering
The message creates urgency by stating that the user's password expires today and warns that failure to verify the account may result in account suspension.

Initial Assessment:
The email contains multiple indicators consistent with credential phishing. Additional analysis is required before assigning a final disposition.
