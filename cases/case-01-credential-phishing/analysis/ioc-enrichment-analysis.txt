CASE 01 - CREDENTIAL PHISHING
IOC ENRICHMENT ANALYSIS

Extracted Suspicious Observables:
- Sender: security@microsoft-account-alert.example
- Reply-To: account-verification@secure-login.example
- Sender Domain: microsoft-account-alert.example
- Reply-To Domain: secure-login.example
- Credential-Verification Domain: login-microsoft365.example
- Credential-Verification URL: https://login-microsoft365.example/verify
- Observed Source IP: 203.0.113.77

Source IP Context:
The IP address 203.0.113.77 appears in the Received header as the source associated with the mail system that delivered the message to the recipient organization's mail system. The available evidence does not establish that this IP hosts the credential-verification website.

Threat Intelligence / Reputation Analysis:
The domains and IP address used in this lab are reserved or simulated values. They were not treated as real malicious infrastructure, and no fabricated threat-intelligence reputation results were assigned to them.

VirusTotal Reference Exercise:
VirusTotal was used with microsoft.com as a benign reference domain to practice interpreting reputation information. At the time of the exercise, VirusTotal showed 0/89 security vendors flagging the domain as malicious.

This result was treated as reputation evidence rather than proof that a domain is safe. Relationships between malicious files and a legitimate domain also do not automatically make the domain malicious.

Analyst Assessment:
IOC enrichment should be correlated with email headers, authentication results, message content, URLs, user activity, and other available telemetry before assigning a final disposition. Threat-intelligence results are supporting evidence and should not be treated as a verdict by themselves.

Case Limitation:
Because this is a controlled phishing simulation using reserved/example infrastructure, real-world reputation results for the simulated phishing indicators are not expected. The VirusTotal lookup was performed as an analyst training exercise and is not evidence about the simulated phishing infrastructure.
